2026-11-24

本站服务

在访问本站时，您的以下信息必然会被处理

  • IP 地址
  • 浏览器与设备信息
  • 访问记录

以下信息在进行反追踪下可能不会被处理

  • 页面性能数据

但本站无法直接接触您的以上信息，根据GA和CF的条款，本站无法接触能定位到自然人的身份信息
如果您并不希望被采集，可使用adblocker或者edge自带反追踪功能拒绝部分遥测访问请求
由于本站部署在cloudflare page上，使用了cf的cdn服务，当您在访问本站时，cf会从服务器后端收集信息，无法通过前端手段进行反追踪，实属抱歉

另外，Cloudflare、Google、GitHub 的服务器都在境外，你在本站产生的数据会跨境传输到它们那里，不过就我的网站来说
你压根没什么可采集的
我也没办法用采集到的信息牟利

第三方服务

除了 Cloudflare 和 Google，页面加载或点击外链时还会碰到下面这些服务
它们各自按自己的隐私政策处理数据，与本站无关。

  • Cloudflare（Pages 托管 / CDN / Web Analytics）——托管网页、匿名流量与性能统计
    政策：Cloudflare 隐私政策 ｜ 说明：Web Analytics 的工作方式
  • Google Analytics 4（Google LLC）——访问统计。涉及：_ga cookie、访问页面、来源、设备与交互信息。
    政策：Google 隐私政策
  • GitHub / giscus（评论系统）——文章下的评论区由 giscus 提供，评论实际存成我 GitHub 仓库里的 Discussion。发评论必须用 GitHub 账号登录，你的 GitHub 用户名、头像和评论内容会公开显示。
    政策：GitHub 隐私声明 ｜ giscus 隐私政策
  • jsDelivr（公共 CDN）——提供 remixicon 图标字体。涉及：IP、Referer。
    政策：jsDelivr 隐私政策
  • 一言 / hitokoto.cn——页脚那句随机语录是向它请求的。涉及：IP、Referer。
    站点：hitokoto.cn

本站友链页内链接采取与本站不同的信息处理方式，具体方式请访问对应链接，联系对应站长

本站使用开往功能进行引流

  • 开往 / travellings.cn——随机跳转到陌生站点。点击之前本站不会向它发任何请求，跳转后由它接管。
    政策：隐私政策 | 开往
